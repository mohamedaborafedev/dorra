# ملخص تقرير الأداء

القياس على نفس 100,000 تصميم، دون حذف الفهارس أو تعديل البيانات.
قاعدة البيانات MySQL 8.4.3، buffer pool بحجم 128MiB، وتوقيت UTC.
التقرير الكامل والـP95 وخطط التنفيذ في [performance.md](../performance.md).

## المنهجية

- baseline بتجاهل الفهارس الثانوية الثلاثة باستخدام IGNORE INDEX؛ indexed دون hint.
- نفس البيانات داخل read-only REPEATABLE READ snapshot، مع فحص بصمة SHA-256 قبل وبعد.
- 3 تشغيلات warmup و20 عينة لكل variant، وترتيب متناوب لتقليل انحياز ترتيب القياس.
- القياس حول PDO SELECT + fetch، وليس زمن الصفحة أو server CPU وحده.
- Warm cache؛ لم تُفرغ caches ولم يُعد تشغيل السيرفر. فرق physical buffer reads أثناء الجولة النهائية صفر.
- EXPLAIN وEXPLAIN ANALYZE محفوظان خارج العينات الزمنية.

هذه مقارنة لمسارات الوصول، وليست تجربة إسقاط وإعادة بناء فعلية للفهرس، ولا تقيس
تكلفة التخزين والكتابة. لم يتم عزل كل أعمال الجهاز الأخرى أو محاكاة إنتاج متزامن.

## نتائج مختارة: الوسيط بالمللي ثانية

| الاستعلام | تجاهل الفهارس | إتاحة الفهارس | الاستنتاج |
| --- | ---: | ---: | --- |
| أحدث 24 تصميمًا | 86.505 | 0.991 | تحسن واضح لأول صفحة |
| قسم + حالة | 47.834 | 1.036 | استفادة من الفهرس المركب |
| بحث Modern مع قسم وحالة | 44.903 | 1.095 | تحسن في هذه البيانات |
| COUNT بدون فلتر | 9.544 | 17.095 | أبطأ مع الخطة المختارة |
| OFFSET 96000 | 117.026 | 125.223 | لا تحسن، scan/filesort في الحالتين |

لا تعني هذه الأرقام تحسن الصفحة بنفس النسبة، ولا تضمن نتائج مماثلة على توزيع بيانات آخر.
لم يُضف فهرس status تلقائيًا. يلزم قياس إضافي قبل تغيير الفهارس أو فرض خطة تنفيذ.

## Playwright

قياسات المتصفح تشمل framework والجلسة وHTML والمتصفح، وتُعرض منفصلة في التقرير التفصيلي.
تجربة الفلاتر والترقيم نجحت، لكن توقيتاتها ليست مقارنة before/after للفهرسة.
بعض رصد المتصفح قد تداخل مع الجولة الأولية لقاعدة البيانات؛ الجولة النهائية لـSQL أُعيدت والمتصفح ساكن.

## حدود مليون تصميم

لم تُولد أو تُقَس مليون سجلات. المطلوب لاحقًا بيانات واقعية بتوزيع غير متجانس،
وقياسات تحت concurrency. راقب COUNT والـOFFSET العميق، وفكّر في cursor pagination
إذا سمح المنتج بتغيير ترقيم الصفحات، وقيّم فهارس القسم/الحالة بناءً على الاستعلامات الواقعية.
قياس الذاكرة والصور والـp95/p99 والكتابة جزء مستقل من تخطيط السعة.
