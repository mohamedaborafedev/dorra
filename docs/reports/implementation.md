# تقرير التنفيذ

## البيئة ونطاق التغييرات

المشروع الحالي Laravel 12.70.2، PHP 8.4.12، MySQL 8.4.3، مع Blade وAlpine.js
وTailwind CSS وLaravelDaily Starter Kit. لم تتم ترقية Laravel إلى 13.
تم الحفاظ على إعدادات الاتصال بقاعدة `dorra` والمستخدم الموجود وبيانات التصميمات.
لم تُنفذ أوامر reset أو migrate:fresh ضد قاعدة البيانات الحالية.

## قاعدة البيانات

- إضافة role إلى users بقيمة افتراضية viewer وقيم مسموحة admin وviewer.
- إنشاء categories: معرف واسم وslug فريد وtimestamps.
- إنشاء designs: معرف وقسم وعنوان وحالة وصورة اختيارية وtimestamps؛ الحالة الافتراضية draft.
- علاقة Category hasMany Design وDesign belongsTo Category، مع منع حذف القسم المرتبط بتصميمات.
- قيود MySQL لقيم الأدوار والحالات، وموديلات وFactories وSeeders.
- فهارس التصميمات: category_id/status/created_at/id، وtitle، وcreated_at/id، بجانب المفتاح الأساسي.
- الفهارس الثانوية ASC وتدعم backward scans للترتيب المطلوب؛ لا يوجد ادعاء بإنشاء فهارس DESC فعلية.
- تثبيت توقيت اتصال MySQL على UTC لتجنب تواريخ غير صالحة في فجوات التوقيت الصيفي.

أعداد البيانات التي تم التحقق منها: 100,000 تصميم، 10 أقسام، 3 مستخدمين
(المستخدم السابق + Admin + Viewer)، 50,000 عنوان عربي و50,000 إنجليزي،
50,001 draft و49,999 published، وصفر تصميمات بلا قسم صالح.
التوليد على دفعات 1,000 ويستكمل العدد دون استبدال البيانات؛ ليس عملية مزامنة آمنة مع كتّاب متزامنين.

## الدخول والتذكّر

الحسابان التجريبيان admin@dorra.test وviewer@dorra.test.
بناءً على طلب المستخدم ضُبطت كلمات مرور الحسابات المحلية على القيمة التجريبية المذكورة
في README، وتُحفظ مشفّرة. التقارير لا تتضمن hashes أو رموز جلسات أو remember tokens.
تم إصلاح checkbox الخاص بـRemember me من قيمة فارغة إلى 1، والتحقق من حفظ التوكن
وإصدار الكوكي واستعادة الدخول دون كوكي الجلسة لكل من Admin وViewer.

## المكتبة والإدارة

- استبدال محتوى /dashboard بجدول Design Library، مع الحفاظ على تسجيل الدخول وإعدادات الحساب.
- أعمدة الصورة والعنوان والقسم والحالة والتاريخ والإجراءات؛ دعم العناوين العربية والوضعين اللونيين.
- Prefix Search مع فلاتر القسم والحالة بشروط AND؛ Apply filters وClear filters.
- التعامل مع % و_ و! كنص عند البحث، مع bindings، وترتيب created_at DESC ثم id DESC.
- Pagination ثابتة 24 نتيجة مع الاحتفاظ بالفلاتر؛ تحميل الأقسام مسبقًا لتجنب N+1.
- CRUD للأدمن مع عرض Draft وPublished، وعرض وبحث Published فقط للمشاهد، مع DesignPolicy على السيرفر وإخفاء الإجراءات غير المسموحة.
- Validation للعنوان والقسم والحالة والصورة، ورسائل نجاح وأخطاء وحالات فارغة و404 للسجلات غير الموجودة.
- صور JPG/PNG/WebP مطلوبة عند إنشاء تصميم حتى 2MB؛ عند التعديل يمكن الاحتفاظ بالصورة الحالية. توجد صور ملابس مشتركة لبيانات العينة.
- تنظيف الصور المستبدلة والمحذوفة والجديدة عند فشل حفظ السجل، دون حذف الصورة المشتركة.
- طلبات الحفظ محمية بـCSRF، والحذف يتطلب تأكيدًا في الواجهة.

## التشغيل وإعادة التحقق

```powershell
php artisan migrate
php artisan db:seed
php artisan db:seed --class=DesignSeeder
php artisan storage:link
npm.cmd run build
php artisan serve
php artisan dorra:verify-database
```

الأوامر موثقة للإعداد؛ لا تستخدمها كإجراء reset للبيانات الموجودة. Seeders التجريبية
مقيّدة ببيئتي local/testing. تفاصيل الإعداد الكامل والحسابات في [README](../../README.md).

## آخر متطلبات العرض والإدارة

Viewer لا يرى Draft في القائمة أو التفاصيل حتى بطلب مباشر، ولا يظهر له فلتر Status.
الأدمن يرى الحالتين وفلتر الحالة. الجدول يخفي اللاحقة الرقمية لعناوين بيانات العينة
دون تعديل المخزون أو أرقام العناوين الحقيقية مثل Logo 2026.
صفحات Users وإضافة وتعديل وحذف الحسابات للأدمن فقط، مع حماية الصلاحيات وCSRF على السيرفر.
